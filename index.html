Cajero.

Pide montos a retirar hasta que el usuario ingrese 0 (centinela) y muestra el total retirado y la cantidad de retiros. Pista: acumulador + contador.

Código PSeInt:

Algoritmo cajero
    Definir monto, total, contador Como Entero
    total <- 0
    contador <- 0

    Escribir "Ingrese el monto a retirar (0 para terminar):"
    Leer monto

    Mientras monto <> 0 Hacer
        total <- total + monto
        contador <- contador + 1

        Escribir "Ingrese otro monto (0 para terminar):"
        Leer monto
    FinMientras

    Escribir "Total retirado: ", total
    Escribir "Cantidad de retiros: ", contador
FinAlgoritmo

Calificaciones.

Dada una lista de notas, calcula el promedio, la nota más alta, la más baja y cuántos estudiantes reprobaron. Pista: cuatro patrones en un solo recorrido.

Código PSeInt:

Algoritmo calificaciones
    Definir n, i, reprobados Como Entero
    Definir nota, suma, promedio, mayor, menor Como Real
    suma <- 0
    reprobados <- 0

    Escribir "Cantidad de estudiantes:"
    Leer n

    Si n > 0 Entonces
        Para i <- 1 Hasta n Hacer
            Escribir "Ingrese la nota del estudiante:"
            Leer nota
            suma <- suma + nota

            Si i = 1 Entonces
                mayor <- nota
                menor <- nota
            SiNo
                Si nota > mayor Entonces
                    mayor <- nota
                FinSi

                Si nota < menor Entonces
                    menor <- nota
                FinSi
            FinSi

            Si nota < 3.0 Entonces
                reprobados <- reprobados + 1
            FinSi
        FinPara

        promedio <- suma / n
        Escribir "Promedio: ", promedio
        Escribir "Nota mayor: ", mayor
        Escribir "Nota menor: ", menor
        Escribir "Estudiantes reprobados: ", reprobados
    SiNo
        Escribir "Error: la cantidad de estudiantes debe ser mayor que 0."
    FinSi
FinAlgoritmo

Validación de usuario.

El usuario tiene 3 intentos para ingresar un correo que contenga "@" y ".". Pista: intentos limitados + bandera.

Código PSeInt:

Algoritmo validarcorreo
    Definir correo Como Cadena
    Definir intentos, i Como Entero
    Definir tieneArroba, tienePunto, valido Como Logico
    intentos <- 0
    valido <- Falso

    Repetir
        tieneArroba <- Falso
        tienePunto <- Falso
        Escribir "Ingrese su correo:"
        Leer correo
        intentos <- intentos + 1

        Para i <- 0 Hasta Longitud(correo) - 1 Hacer
            Si SubCadena(correo, i, i) = "@" Entonces
                tieneArroba <- Verdadero
            FinSi
            Si SubCadena(correo, i, i) = "." Entonces
                tienePunto <- Verdadero
            FinSi
        FinPara

        Si tieneArroba Y tienePunto Entonces
            valido <- Verdadero
        FinSi
    Hasta Que valido O intentos = 3

    Si valido Entonces
        Escribir "Correo valido."
    SiNo
        Escribir "Se agotaron los intentos."
    FinSi
FinAlgoritmo

Pirámide.

Imprime una pirámide de asteriscos de n niveles. Pista: ciclos anidados; haz la traza para n = 3.

Código PSeInt:

Algoritmo piramide
    Definir n, i, j, k Como Entero
    Escribir "Ingrese el numero de niveles:"
    Leer n

    Para i <- 1 Hasta n Hacer
        Para k <- 1 Hasta n - i Hacer
            Escribir Sin Saltar " "
        FinPara
        Para j <- 1 Hasta 2 * i - 1 Hacer
            Escribir Sin Saltar "*"
        FinPara
        Escribir ""
    FinPara
FinAlgoritmo

Factura de restaurante.

Descompón en funciones el cálculo de una cuenta con propina opcional, división entre comensales y redondeo. Pista: define primero la tabla de firmas.

Tabla de subprocesos (firmas):

Firma de cada subproceso
Subproceso Parámetros de entrada Retorno
CalcularSubtotal cantidad (Entero), precio (Real) Subtotal (Real)
CalcularPropina subtotal (Real), aplica (Cadena) Valor propina (Real)
DividirCuenta total (Real), comensales (Entero) Valor por persona (Real)
RedondearValor valor (Real) Valor redondeado (Real)

Código PSeInt:

Funcion subtotal <- CalcularSubtotal(cantidad, precio)
    Definir subtotal Como Real
    subtotal <- cantidad * precio
FinFuncion

Funcion propina <- CalcularPropina(subtotal, aplica)
    Definir propina Como Real

    Si aplica = "S" O aplica = "s" Entonces
        propina <- subtotal * 0.10
    SiNo
        propina <- 0
    FinSi
FinFuncion

Funcion valor <- DividirCuenta(total, comensales)
    Definir valor Como Real
    valor <- total / comensales
FinFuncion

Funcion resultado <- RedondearValor(valor)
    Definir resultado Como Real
    resultado <- Redon(valor)
FinFuncion

Algoritmo factura_restaurante
    Definir cantidad, comensales Como Entero
    Definir precio, subtotal, propina, total Como Real
    Definir valorPersona, valorFinal Como Real
    Definir aplica Como Cadena

    Escribir "Cantidad de platos:"
    Leer cantidad

    Escribir "Precio por plato:"
    Leer precio

    Escribir "Desea incluir propina? S/N"
    Leer aplica

    Escribir "Cantidad de comensales:"
    Leer comensales

    Si cantidad > 0 Y precio >= 0 Y comensales > 0 Entonces
        subtotal <- CalcularSubtotal(cantidad, precio)
        propina <- CalcularPropina(subtotal, aplica)
        total <- subtotal + propina
        valorPersona <- DividirCuenta(total, comensales)
        valorFinal <- RedondearValor(valorPersona)

        Escribir "Subtotal: $", subtotal
        Escribir "Propina: $", propina
        Escribir "Total factura: $", total
        Escribir "Valor por persona: $", valorFinal
    SiNo
        Escribir "Error: Verifique los datos ingresados."
    FinSi
FinAlgoritmo
