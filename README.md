Patrones de repetición y descomposición de problemas: Se desarrollan ejercicios prácticos de programación aplicando estructuras repetitivas, acumuladores, contadores, validaciones y ciclos anidados en PSeInt. Adicionalmente, se implementa la descomposición de problemas mediante subprocesos y la representación de árboles de componentes, fortaleciendo el pensamiento lógico y la organización del código.
